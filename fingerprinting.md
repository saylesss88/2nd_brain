## Naive Scripts

A **naive script** in browser fingerprinting refers to a simple, straightforward
script that collects basic and obvious information from the browser environment
to create a fingerprint. This might include gathering common properties like the
User-Agent string, screen resolution, timezone, and installed fonts or plugins
using standard JavaScript APIs. Naive scripts usually operate without much
obfuscation or complexity and are easier to detect and block. They target
easy-to-access attributes, mainly relying on passive data that browsers expose
by default.

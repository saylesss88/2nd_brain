# Zed Commands

- [zed commands cheat sheet](https://cheatsheets.zip/zed)

| Action              | Linux              |
| :------------------ | :----------------- |
| Command palette     | `Ctrl+Shift+P`     |
| Go to file          | `Ctrl+P`           |
| Go to symbol        | `Ctrl+Shift+O`     |
| Find in project     | `Ctrl+Shift+F`     |
| Toggle terminal     | `Ctrl+``           |
| Open settings       | `Ctrl+,`           |
| Open Agent Panel    | `Ctrl+Shift+A`     |
| Trigger Completions | `Ctrl+Space`       |
| Quit Zed            | `Ctrl+Q`           |
| New File            | `Ctrl+N`           |
| New Folder          | `Ctrl+Shift+N`     |
| Open remote folder  | `Ctrl+Alt+Shift+O` |
| Undo                | `Ctrl+Z`           |
| Redo                | `Ctrl+Shift+Z`     |
| Copy                | `Ctrl+C`           |
| Paste               | `Ctrl+V`           |
| Toggle Comment      | `Ctrl+/`           |
| Select All          | `Ctrl+A`           |
| Diagnostics         | `Ctrl+Shift+M`     |
